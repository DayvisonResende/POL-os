## TabNews (publicação)

**Título:** Fiz um jogo de investigação para aprender SQL do zero (grátis, no navegador)

Quem aprende SQL costuma travar no mesmo lugar: decorar comando sem ter uma pergunta de verdade para responder. Fiz o Pol-OS para atacar isso.

**Como funciona.** Você é recruta num departamento de investigação fictício. Cada caso é um crime (um furto no shopping, um caminhão roubado, dinheiro que passa por contas de laranjas) e a única ferramenta é um terminal SQL com um banco de dados SQLite rodando no próprio navegador.

**O que ensina hoje.** Módulos 1 a 4: `SELECT`, `WHERE`, `LIKE`, `BETWEEN`, `ORDER BY`, `COUNT`/`SUM`/`GROUP BY`/`HAVING`, `NULL` e `COALESCE`, `JOIN` e `LEFT JOIN`. Cada módulo tem um treinamento guiado e casos para resolver.

**Para iniciante de verdade:**
- os erros do SQLite são traduzidos para o português, e o editor sublinha a palavra onde a consulta quebrou;
- o botão "Explique esta consulta" traduz qualquer consulta, pedaço por pedaço;
- cada tarefa tem dicas em degraus, do empurrãozinho até a consulta pronta.

**Para quem já sabe SQL:** existe um nivelamento ("Já sei SQL") que pula o que você já domina.

**Técnico, para quem se interessa:** HTML, CSS e JavaScript puros, sem build; sql.js (SQLite em WebAssembly); o progresso fica no navegador; telemetria anônima e opcional, com termo de uso.

**Folha-resumo:** fiz também o "Manual do Recruta", todo o SQL do jogo em uma página, em PDF: https://polos.useconectai.com.br/manual/
