A ordem das partesSELECT colunas FROM tabela WHERE filtro GROUP BY grupo HAVING filtro do grupo ORDER BY coluna LIMIT n; · só SELECT e FROM são obrigatórios; o resto, quando precisar, nesta ordem.

Módulo 1 Ler uma tabela

SELECT … FROM

Mostra colunas de uma tabela. O * traz todas.

SELECT placa, modelo FROM veiculos;
DISTINCT

Tira as linhas repetidas do resultado.

SELECT DISTINCT cidade FROM pessoas;
AS

Apelido para a coluna no resultado. O banco não muda.

SELECT modelo AS veiculo FROM veiculos;
LIMIT

Corta o resultado. Vai sempre no fim.

SELECT * FROM veiculos LIMIT 5;

Módulo 2 Filtrar

WHERE

Só as linhas que passam na condição. Texto vai entre aspas simples.

SELECT placa, modelo FROM veiculos WHERE cor = 'branco';
AND / OR

AND: as duas condições. OR: qualquer uma delas.

SELECT placa FROM veiculos WHERE cor = 'azul' AND ano >= 2015;
= != > < >= <=

Igual, diferente, maior, menor, maior ou igual, menor ou igual.

SELECT placa, velocidade_kmh FROM leituras_radar WHERE local_radar = 'Av. Dom Aguirre' AND velocidade_kmh > 60;
LIKE e %

Texto parecido. O % vale "qualquer coisa".

SELECT nome FROM pessoas WHERE nome LIKE 'Mar%';
BETWEEN

Entre dois valores, incluindo as duas pontas.

SELECT placa, ano FROM veiculos WHERE ano BETWEEN 2018 AND 2020;
Data e hora

No formato AAAA-MM-DD HH:MM:SS. Para um dia inteiro, use as duas pontas.

SELECT placa, data_hora FROM leituras_radar WHERE data_hora BETWEEN '2026-10-13 00:00:00' AND '2026-10-13 23:59:59';
IN

Um valor de uma lista.

SELECT nome, cidade FROM pessoas WHERE cidade IN ('Itu', 'Salto');
ORDER BY

Ordena. ASC do menor ao maior, DESC do maior ao menor.

SELECT placa, ano FROM veiculos ORDER BY ano DESC;

Módulo 3 Contar e somar

COUNT

Quantas linhas. COUNT(coluna) não conta as vazias.

SELECT COUNT(*) FROM veiculos WHERE cor = 'preto';
SUM e AVG

Soma e média de uma coluna de números.

SELECT AVG(velocidade_kmh) FROM leituras_radar WHERE local_radar = 'Av. Dom Aguirre';
MIN e MAX

O menor e o maior (também com datas).

SELECT MIN(ano), MAX(ano) FROM veiculos;
GROUP BY

Uma conta para cada grupo: "de cada", "por".

SELECT ano, COUNT(*) FROM veiculos GROUP BY ano;
HAVING

Filtra os grupos, depois da conta. O WHERE filtra as linhas, antes.

SELECT ano, COUNT(*) FROM veiculos GROUP BY ano HAVING COUNT(*) >= 3;
IS NULL

Vazio (NULL) não é igual a nada: use IS NULL ou IS NOT NULL.

SELECT id, valor FROM transferencias WHERE descricao IS NULL;
COALESCE

Troca o vazio por um valor, só na hora de mostrar.

SELECT id, COALESCE(descricao, 'sem descrição') FROM transferencias;

Módulo 4 Juntar tabelas

JOIN … ON

Junta duas tabelas pela coluna que elas têm em comum.

SELECT v.placa, p.nome FROM veiculos v JOIN pessoas p ON p.cpf = v.cpf_proprietario WHERE p.cidade = 'Salto';
Apelido de tabela

veiculos v: depois, v.placa diz de qual tabela é a coluna.

LEFT JOIN

Mantém todas as linhas da tabela da esquerda, mesmo sem par (o lado sem par vem NULL).

SELECT p.nome, v.placa FROM pessoas p LEFT JOIN veiculos v ON v.cpf_proprietario = p.cpf;
Quem não tem

LEFT JOIN + IS NULL: as pessoas sem nenhum veículo.

SELECT p.nome FROM pessoas p LEFT JOIN veiculos v ON v.cpf_proprietario = p.cpf WHERE v.placa IS NULL;

Os tropeços mais comuns

  • Texto sem aspas: cor = branco procura uma coluna chamada branco. O certo: cor = 'branco'.
  • Vírgula sobrando antes do FROM: SELECT placa, modelo, FROM. A última coluna não leva vírgula.
  • = NULL não funciona: volta vazio sem avisar. Use IS NULL.
  • WHERE depois do GROUP BY: para filtrar o resultado da conta, é HAVING.
  • Soma que infla no JOIN: se um lado tem várias linhas para cada linha do outro, o valor se repete na soma.
